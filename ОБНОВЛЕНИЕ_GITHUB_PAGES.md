# Обновление GitHub Pages

## Проблема
Изменения не отображаются на сайте из-за кэша браузера или GitHub Pages.

## Решение

### 1. Очистить кэш браузера
- **Chrome/Edge**: Ctrl + Shift + Delete → Очистить кэш
- **Safari**: Cmd + Option + E
- Или открыть в режиме инкогнито

### 2. Жесткая перезагрузка страницы
- **Windows**: Ctrl + F5 или Ctrl + Shift + R
- **Mac**: Cmd + Shift + R

### 3. Обновить GitHub Pages
1. Открой репозиторий на GitHub
2. Перейди в **Settings** → **Pages**
3. Нажми **Save** (даже если ничего не менял)
4. Подожди 1-2 минуты

### 4. Проверить версию
- Открой сайт
- Посмотри на версию в профиле (должно быть **v45**)
- Если версия старая - повтори шаги 1-3

✅ **Кнопки правильного цвета** - урна красная, карандаш прозрачный
✅ **Текст в каталоге** - "Выбери группу мышц" теперь обычного размера

## Если не помогло

1. Проверь что файлы скопированы в GitHub папку
2. Сделай commit и push в GitHub
3. Подожди 5 минут для обновления GitHub Pages
4. Очисти кэш и перезагрузи страницу
